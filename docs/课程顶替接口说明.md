# 课程顶替接口说明

## 一、说明

本文档对应《实施计划》第四阶段 4.3 任务，覆盖课程顶替规则维护、课程顶替申请和审核接口。

- 规则数据保存于 `course_replacement_rule`。
- 申请主数据保存于 `business_application`，业务类型为 `COURSE_REPLACE`。
- 申请差异字段保存于 `application_extension_field`，并同步写入 `business_application.extension_data_json`。
- 提交、修改、撤回、审核通过、审核驳回等流程动作写入 `audit_record`。

## 二、规则接口

### 1. 分页查询规则

- 请求方式：`GET`
- 请求路径：`/api/course-replacements/rules/page`

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| pageNo | 否 | 当前页码，默认 `1`。 |
| pageSize | 否 | 每页条数，默认 `10`。 |
| keyword | 否 | 可匹配原课程、顶替课程和专业代码。 |
| ruleStatus | 否 | 规则状态：`ENABLED`、`DISABLED`。 |

### 2. 新增规则

- 请求方式：`POST`
- 请求路径：`/api/course-replacements/rules`

请求体示例：

```json
{
  "sourceCourseCode": "03708",
  "sourceCourseName": "中国近现代史纲要",
  "targetCourseCode": "12656",
  "targetCourseName": "毛泽东思想和中国特色社会主义理论体系概论",
  "majorCode": null,
  "educationLevel": null,
  "credit": 2,
  "effectiveDate": "2026-01-01",
  "expireDate": null,
  "remark": "公共政治课顶替规则"
}
```

### 3. 修改规则状态

- 请求方式：`PUT`
- 请求路径：`/api/course-replacements/rules/{id}/status`

请求体示例：

```json
{
  "ruleStatus": "DISABLED"
}
```

## 三、申请接口

### 1. 分页查询申请

- 请求方式：`GET`
- 请求路径：`/api/course-replacements/applications/page`

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| pageNo | 否 | 当前页码，默认 `1`。 |
| pageSize | 否 | 每页条数，默认 `10`。 |
| keyword | 否 | 可匹配申请编号、申请标题、课程快照、考籍号和考生摘要。 |
| applicationStatus | 否 | 申请状态：`SUBMITTED`、`APPROVED`、`REJECTED`、`WITHDRAWN`。 |
| recordId | 否 | 考籍档案 ID。 |
| candidateId | 否 | 考生 ID。 |

### 2. 提交申请

- 请求方式：`POST`
- 请求路径：`/api/course-replacements/applications`

请求体示例：

```json
{
  "recordId": 1,
  "ruleId": 1,
  "applyReason": "已完成原课程学习并取得合格成绩，申请按规则顶替。",
  "materialIds": [1],
  "remark": "课程顶替申请"
}
```

提交时会校验：

- 考籍档案必须存在。
- 规则必须启用且处于有效期内。
- 规则的专业和学历层次必须适用于当前考籍档案。
- 申请材料必须属于当前考籍档案。
- 同一档案、同一原课程和顶替课程不能重复存在已提交或已通过申请。

### 3. 审核申请

- 审核通过：`PUT /api/course-replacements/applications/{id}/approve`
- 审核驳回：`PUT /api/course-replacements/applications/{id}/reject`

请求体示例：

```json
{
  "auditOpinion": "材料完整，符合课程顶替规则。"
}
```

## 四、状态流转

| 动作 | 前置状态 | 目标状态 |
| --- | --- | --- |
| 提交 | 无 | `SUBMITTED` |
| 修改 | `SUBMITTED` | `SUBMITTED` |
| 撤回 | `SUBMITTED` | `WITHDRAWN` |
| 审核通过 | `SUBMITTED` | `APPROVED` |
| 审核驳回 | `SUBMITTED` | `REJECTED` |

## 五、关键响应字段

| 字段 | 说明 |
| --- | --- |
| ruleId | 课程顶替规则 ID。 |
| sourceCourseCode | 原课程代码。 |
| sourceCourseName | 原课程名称。 |
| targetCourseCode | 顶替课程代码。 |
| targetCourseName | 顶替课程名称。 |
| majorCode | 适用专业代码。 |
| educationLevel | 适用学历层次。 |
| applyReason | 申请原因。 |
| materialIds | 申请材料 ID 列表。 |
