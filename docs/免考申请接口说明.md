# 免考申请接口说明

## 一、接口范围

本文档对应第四阶段 4.2 任务，覆盖免考申请提交、修改、撤回、审核通过、审核驳回、分页查询、详情查询和流程记录查询接口。

免考申请主数据保存于 `business_application` 表，业务类型固定为 `EXEMPTION`。免考课程、证明来源课程和免考原因同时保存到 `extension_data_json` 快照与 `application_extension_field` 明细表，流程动作保存到 `audit_record` 表。

## 二、接口列表

| 功能 | 请求方式 | 地址 |
| --- | --- | --- |
| 分页查询免考申请 | GET | `/api/exemptions/page` |
| 查询免考申请详情 | GET | `/api/exemptions/{id}` |
| 提交免考申请 | POST | `/api/exemptions` |
| 修改免考申请 | PUT | `/api/exemptions/{id}` |
| 撤回免考申请 | PUT | `/api/exemptions/{id}/withdraw` |
| 审核通过免考申请 | PUT | `/api/exemptions/{id}/approve` |
| 驳回免考申请 | PUT | `/api/exemptions/{id}/reject` |
| 查询免考流程记录 | GET | `/api/exemptions/{id}/flow-records` |

## 三、状态约定

| 状态 | 说明 | 是否允许修改 | 是否允许撤回 |
| --- | --- | --- | --- |
| `SUBMITTED` | 已提交，等待审核 | 是 | 是 |
| `APPROVED` | 审核通过 | 否 | 否 |
| `REJECTED` | 审核驳回 | 否 | 否 |
| `WITHDRAWN` | 已撤回 | 否 | 否 |

流程记录动作 `auditAction` 取值：

| 动作 | 说明 |
| --- | --- |
| `SUBMIT` | 提交申请 |
| `UPDATE` | 修改申请 |
| `APPROVE` | 审核通过 |
| `REJECT` | 审核驳回 |
| `WITHDRAW` | 撤回申请 |

## 四、请求示例

### 1. 提交免考申请

```json
{
  "recordId": 2,
  "courseCode": "00015",
  "courseName": "英语（二）",
  "sourceCourseCode": "CET4",
  "sourceCourseName": "大学英语四级",
  "exemptionReason": "已取得大学英语四级成绩证明，申请免考英语（二）。",
  "materialIds": [2],
  "remark": "考生线上提交免考申请"
}
```

### 2. 修改免考申请

```json
{
  "courseCode": "00015",
  "courseName": "英语（二）",
  "sourceCourseCode": "CET4",
  "sourceCourseName": "大学英语四级",
  "exemptionReason": "补充成绩证明编号后重新提交。",
  "materialIds": [2],
  "remark": "补充材料说明"
}
```

### 3. 撤回免考申请

```json
{
  "withdrawReason": "考生暂不办理该课程免考。"
}
```

### 4. 审核通过或驳回

```json
{
  "auditOpinion": "材料真实有效，同意该课程免考。"
}
```

驳回接口使用同样请求体，`auditOpinion` 填写驳回原因。

## 五、查询参数

分页查询接口支持以下参数：

| 参数 | 说明 |
| --- | --- |
| `pageNo` | 当前页码，默认 `1` |
| `pageSize` | 每页条数，默认 `10` |
| `keyword` | 查询关键字，可匹配申请编号、标题、扩展字段、考籍号、考生姓名、身份证号和准考证号 |
| `applicationStatus` | 申请状态 |
| `recordId` | 考籍档案 ID |
| `candidateId` | 考生 ID |

## 六、业务规则

- 提交前校验考籍档案是否存在。
- 申请材料如传入 `materialIds`，必须属于当前考籍档案。
- 同一考籍档案、同一课程不允许同时存在 `SUBMITTED` 或 `APPROVED` 状态的免考申请。
- 只有 `SUBMITTED` 状态可以修改、撤回、审核通过或驳回。
- 每次提交、修改、撤回、通过和驳回都会写入 `audit_record`，用于流程记录查询。
