# 部署与使用说明

## 一、说明

本文档对应《实施计划》第六阶段 6.7 中的部署说明和使用说明，面向本地联调、课程验收和演示环境搭建。

系统由三部分组成：

- 后端服务：Spring Boot，默认端口 `8088`。
- 前端应用：Vue3 + Vite，默认端口 `5173`。
- 算法服务：FastAPI，默认端口 `9000`。

## 二、环境要求

| 组件 | 建议版本 | 用途 |
| --- | --- | --- |
| JDK | 17 | 编译和运行 Spring Boot 后端 |
| Maven | 3.8+ | 后端依赖管理和测试 |
| Node.js | 18+ | 前端依赖安装、开发服务和生产构建 |
| Python | 3.10+ | 算法服务运行和测试 |
| MySQL | 8.0+ | 业务数据库 |

## 三、数据库初始化

1. 创建数据库和表结构：

```bash
mysql -uroot -p < sql/init.sql
```

2. 导入演示数据：

```bash
mysql -uroot -p exam_record < sql/test-data.sql
```

3. 默认数据库连接配置位于 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/exam_record?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
```

如本地 MySQL 账号或密码不同，需要先修改该配置。

## 四、后端服务

### 1. 配置项

主要配置文件：`backend/src/main/resources/application.yml`

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `server.port` | `8088` | 后端服务端口 |
| `auth.token.secret` | `examination-file-management-local-secret` | Token 签名密钥 |
| `auth.token.expire-seconds` | `7200` | Token 有效期，单位秒 |
| `algorithm.service.base-url` | `http://localhost:9000/api` | 算法服务业务接口地址 |
| `algorithm.service.api-key` | `examination-algorithm-local-key` | 后端访问算法服务的内部密钥 |
| `file.storage.material-root` | `uploads/materials` | 后端材料文件保存目录 |

### 2. 启动命令

```bash
cd backend
mvn spring-boot:run
```

### 3. 健康检查

```bash
curl http://localhost:8088/api/health
```

预期返回：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "status": "UP",
    "service": "考籍管理系统后端"
  }
}
```

### 4. 回归命令

```bash
cd backend
mvn test
```

当前已覆盖无登录凭证访问认证接口和空 Token 校验场景。

## 五、算法服务

### 1. 环境配置

```bash
cd algorithm-service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
copy .env.example .env
```

`.env.example` 中包含以下配置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | `your-deepseek-api-key` | DeepSeek API Key；未配置时系统使用本地规则兜底问答 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | DeepSeek 接口地址 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | DeepSeek 模型名称 |
| `MATERIAL_UPLOAD_ROOT` | `../backend/uploads/materials` | 算法服务读取后端上传材料的本地目录 |
| `ALGORITHM_SERVICE_API_KEY` | 未显式写入 `.env.example` | 可选；如配置，必须与后端 `algorithm.service.api-key` 一致 |

### 2. 启动命令

```bash
cd algorithm-service
python -m uvicorn app.main:app --host 127.0.0.1 --port 9000 --reload
```

### 3. 健康检查

```bash
curl http://localhost:9000/health
```

### 4. 接口测试

```bash
cd algorithm-service
python -m compileall app
python -m pytest
```

当前 pytest 覆盖健康检查、内部密钥鉴权、智能问答统一响应、参数校验和空材料核验。

## 六、前端应用

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 启动开发服务

```bash
npm run dev
```

默认访问地址：

```text
http://localhost:5173
```

前端开发服务已在 `frontend/vite.config.ts` 中将 `/api` 和 `/uploads` 代理到 `http://localhost:8088`。

### 3. 生产构建

```bash
cd frontend
npm run build
```

当前构建已配置 Vue、Element Plus 和公共依赖分包，并过滤已知第三方注释提示。

## 八、推荐启动顺序

1. 启动 MySQL，并执行 `sql/init.sql` 和 `sql/test-data.sql`。
2. 启动算法服务，确认 `http://localhost:9000/health` 正常。
3. 启动后端服务，确认 `http://localhost:8088/api/health` 正常。
4. 启动前端服务，打开 `http://localhost:5173`。
5. 使用默认演示账号登录并执行演示流程。

## 九、常见问题

### 1. 登录失败或接口提示数据库连接失败

检查 MySQL 是否启动，数据库名是否为 `exam_record`，以及 `application.yml` 中用户名和密码是否正确。

### 2. 智能辅助接口不可用

检查算法服务是否启动在 `9000` 端口，后端配置的 `algorithm.service.base-url` 和 `algorithm.service.api-key` 是否与算法服务一致。

### 3. 材料预览或下载失败

检查后端 `file.storage.material-root` 指向的目录是否存在，文件是否由材料上传接口生成。演示脚本中的材料路径为样例记录，真实预览需要对应文件存在。

### 4. 前端页面提示网络异常

检查前端开发服务代理、后端端口 `8088` 和浏览器访问地址是否正确。开发环境应通过 `http://localhost:5173` 访问前端。

### 5. 删除类操作如何验证

根据项目协作约定，禁止批量删除文件或数据。删除类接口和页面仅使用临时新增的测试数据验证；如需清理历史测试数据，应先确认清理范围。
