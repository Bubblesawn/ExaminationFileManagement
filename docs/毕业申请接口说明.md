# 毕业申请接口说明

## 一、接口概述

毕业申请接口对应第四阶段 4.5 任务，提供毕业申请提交、资格校验、审核、驳回、结果查询和流程记录查询能力。接口统一使用后端通用响应结构，业务数据写入 `business_application` 通用申请表，毕业批次、学位申请类型、资格校验结果等差异字段写入 `extension_data_json` 和 `application_extension_field`。

## 二、业务规则

- 毕业申请业务类型固定为 `GRADUATION`。
- 同一考籍档案只能存在一个在办或已通过的毕业申请。
- 提交和修改毕业申请时会执行毕业资格校验，校验不通过时拒绝保存。
- 审核通过前会再次执行毕业资格校验，避免材料或档案状态在提交后发生变化。
- 审核通过后，考籍档案状态更新为 `GRADUATED`，并写入档案状态记录和档案变更记录。
- 审核驳回后，申请进入 `REJECTED` 终态，档案状态不联动变更。

## 三、资格校验口径

当前版本基于现有数据完成基础资格校验：

| 校验项 | 通过条件 |
| --- | --- |
| 考籍状态 | `student_record.record_status = NORMAL` |
| 档案基础信息 | 考籍号、专业名称、考籍层次均不为空 |
| 考生身份信息 | 考生姓名、身份证号均不为空 |
| 毕业申请材料 | 当前档案存在 `GRADUATION` 类型材料 |
| 材料审核状态 | 所有毕业申请材料审核状态均为 `APPROVED` |

若档案已归档，会作为提醒项返回，不直接阻断申请。

## 四、接口列表

### 1. 分页查询毕业申请

- 请求方式：`GET`
- 请求地址：`/api/graduations/page`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageNo | number | 否 | 当前页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 申请编号、标题、备注、考生姓名、身份证号、准考证号、考籍号、专业关键字 |
| applicationStatus | string | 否 | 申请状态 |
| recordId | number | 否 | 考籍档案 ID |
| candidateId | number | 否 | 考生 ID |

### 2. 查询毕业申请详情

- 请求方式：`GET`
- 请求地址：`/api/graduations/{id}`

### 3. 校验毕业资格

- 请求方式：`GET`
- 请求地址：`/api/graduations/eligibility/{recordId}`

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| eligible | boolean | 是否具备毕业申请资格 |
| passedItems | array | 已通过校验项 |
| failedItems | array | 未通过校验项 |
| warningItems | array | 提醒项 |

### 4. 提交毕业申请

- 请求方式：`POST`
- 请求地址：`/api/graduations`

请求体：

```json
{
  "recordId": 4,
  "graduationBatch": "2026年上半年",
  "degreeApplyType": "DEGREE",
  "applyReason": "课程计划已完成，申请毕业审核。",
  "materialIds": [5],
  "remark": "测试毕业申请"
}
```

### 5. 修改毕业申请

- 请求方式：`PUT`
- 请求地址：`/api/graduations/{id}`

说明：仅允许 `SUBMITTED` 状态的毕业申请修改。

### 6. 撤回毕业申请

- 请求方式：`PUT`
- 请求地址：`/api/graduations/{id}/withdraw`

请求体：

```json
{
  "withdrawReason": "申请信息需要重新核对。"
}
```

### 7. 审核通过毕业申请

- 请求方式：`PUT`
- 请求地址：`/api/graduations/{id}/approve`

请求体：

```json
{
  "auditOpinion": "毕业资格和材料审核通过。"
}
```

### 8. 驳回毕业申请

- 请求方式：`PUT`
- 请求地址：`/api/graduations/{id}/reject`

请求体：

```json
{
  "auditOpinion": "毕业材料不完整，请补充后重新提交。"
}
```

### 9. 查询毕业申请结果

- 请求方式：`GET`
- 请求地址：`/api/graduations/{id}/result`

说明：仅当申请状态为 `APPROVED` 或 `REJECTED` 时返回结果。

### 10. 查询流程记录

- 请求方式：`GET`
- 请求地址：`/api/graduations/{id}/flow-records`

## 五、主要响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 毕业申请 ID |
| applicationNo | string | 申请编号 |
| businessType | string | 固定为 `GRADUATION` |
| recordId | number | 考籍档案 ID |
| recordNo | string | 考籍号 |
| recordStatus | string | 当前考籍状态 |
| candidateId | number | 考生 ID |
| candidateName | string | 考生姓名 |
| applicationStatus | string | 申请状态 |
| graduationBatch | string | 申请毕业批次 |
| degreeApplyType | string | 学位申请类型 |
| applyReason | string | 申请原因 |
| eligibilityPassed | boolean | 资格校验是否通过 |
| eligibilitySummary | string | 资格校验摘要 |
| materialIds | array | 申请材料 ID |
| auditOpinion | string | 审核意见 |
| auditTime | string | 审核时间 |

## 六、状态说明

| 状态 | 说明 |
| --- | --- |
| SUBMITTED | 已提交，允许修改、撤回和审核 |
| APPROVED | 审核通过，终态 |
| REJECTED | 审核驳回，终态 |
| WITHDRAWN | 已撤回，终态 |
