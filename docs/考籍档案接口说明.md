# 考籍档案接口说明

## 一、接口范围

本文档对应第三阶段 3.3 与 3.5 任务，覆盖考籍档案创建、编辑、分页查询、详情查询、归档、状态更新和档案变更记录查询接口。

## 二、接口列表

| 功能 | 请求方式 | 地址 |
| --- | --- | --- |
| 分页查询档案 | GET | `/api/records/page` |
| 查询档案详情 | GET | `/api/records/{id}` |
| 创建档案 | POST | `/api/records` |
| 编辑档案 | PUT | `/api/records/{id}` |
| 更新档案状态 | PUT | `/api/records/{id}/status` |
| 档案归档 | PUT | `/api/records/{id}/archive` |
| 分页查询档案变更记录 | GET | `/api/records/{id}/change-logs/page` |

## 三、状态约定

考籍状态 `recordStatus` 支持以下值：

| 值 | 说明 |
| --- | --- |
| `NORMAL` | 正常 |
| `SUSPENDED` | 暂停 |
| `CANCELLED` | 注销 |
| `TRANSFERRED_OUT` | 已转出 |
| `GRADUATED` | 已毕业 |

归档状态 `archiveStatus` 支持以下值：

| 值 | 说明 |
| --- | --- |
| `UNARCHIVED` | 未归档 |
| `ARCHIVED` | 已归档 |

## 四、请求示例

### 1. 创建档案

```json
{
  "candidateId": 1,
  "recordNo": "KJ20260005",
  "enrollBatch": "2026年春季",
  "educationLevel": "本科",
  "majorCode": "080901",
  "majorName": "计算机科学与技术",
  "recordStatus": "NORMAL",
  "remark": "新建考籍档案"
}
```

### 2. 更新状态

```json
{
  "recordStatus": "SUSPENDED",
  "changeReason": "考生材料待补正，暂缓办理"
}
```

### 3. 档案归档

```json
{
  "archiveReason": "阶段材料已审核完成，档案归档"
}
```

### 4. 查询档案变更记录

```text
GET /api/records/1/change-logs/page?pageNo=1&pageSize=10&changeType=UPDATE
```

响应数据中的 `records` 字段示例：

```json
[
  {
    "id": 1,
    "recordId": 1,
    "changeType": "UPDATE",
    "changeField": "majorName",
    "beforeValue": "行政管理",
    "afterValue": "计算机科学与技术",
    "changeReason": "编辑考籍档案",
    "operatorId": 1,
    "operatorName": "系统管理员",
    "operationTime": "2026-05-27T10:30:00"
  }
]
```

## 五、业务说明

- 创建档案时会校验考生是否存在、考籍号是否唯一。
- 创建档案默认归档状态为 `UNARCHIVED`。
- 状态更新会写入 `record_status_log`，记录变更前状态、变更后状态、变更原因和操作人。
- 创建档案、编辑档案、状态更新和归档会自动写入 `record_change_log`，用于展示档案变更轨迹。
- 变更记录查询支持按 `changeType` 筛选，取值为 `CREATE`、`UPDATE`、`ARCHIVE`、`STATUS_CHANGE`、`MATERIAL_CHANGE`。
- 归档接口只允许执行一次，重复归档会返回业务错误。
