1. `mvn test` 执行成功，后端项目可编译，Maven 测试生命周期无异常。
2. 登录认证接口已实现登录、退出和当前用户校验能力。

7. 考籍核心业务接口已覆盖考生、考籍档案、材料类型、材料上传预览下载和档案变更记录。
8. 业务流程接口已覆盖免考、课程顶替、转入转出、毕业申请和通用流程记录查询。
9. 业务流程服务已包含重复申请、终态限制、材料归属、资格校验和档案状态联动等关键校验。

12. 操作日志拦截器已注册到业务接口，排除了登录、健康检查、日志查询和接口文档地址。

## 五、重点问题清单

### 1. 后端缺少自动化接口测试用例

问题等级：中

现象说明：

`mvn test` 当前执行成功，但 Maven 输出显示没有测试源码可编译，也没有测试用例运行。

影响范围：

- 当前 6.2 自测结果仍以代码审查、编译验证和后续人工接口执行为主。
- 登录、权限、流程状态流转、智能辅助异常兜底等关键路径缺少可重复回归保障。

建议修复方向：

1. 在 `backend/src/test/java` 下补充 Spring Boot 集成测试。
2. 优先覆盖登录成功、登录失败、无 Token、无权限、考籍状态变更、流程审核、算法服务异常等关键路径。
3. 对算法服务调用使用 Mock 或测试配置，避免自动化测试依赖外部服务可用性。
4. 将 `mvn test` 纳入交付前固定检查命令。

### 2. 需要补充真实运行环境接口执行记录

问题等级：中

现象说明：

本次已完成后端编译检查和接口覆盖范围梳理，但尚未在已启动的 MySQL、后端和算法服务环境中逐条执行完整 HTTP 调用。

影响范围：

- 数据库初始化、测试数据状态、算法服务可用性和本地端口占用等运行时因素仍可能暴露问题。
- 文件上传、下载、预览、ASR 文件上传等 multipart 场景无法仅靠编译验证确认。

建议修复方向：

1. 按本文档第四章接口自测用例清单执行 Postman、Apifox 或 curl 调用。
2. 保存关键请求、响应和截图，作为 6.5 三端联调输入。
3. 将执行失败项追加到本文档“待整改问题”中，并在 6.6 回归时逐项关闭。

### 3. 删除类接口测试需先确认数据范围

问题等级：低

现象说明：

后端包含用户、角色、菜单、考生、材料等删除接口。根据项目协作约定，禁止批量删除文件或数据，删除前需要确认范围。

影响范围：

- 测试删除接口时如果直接使用演示基础数据，可能影响后续演示和联调。

建议修复方向：

1. 删除类接口仅使用带时间戳的临时测试数据。
2. 删除测试前记录数据 ID、业务含义和清理范围。
3. 不执行批量删除；如需清理历史测试数据，先向用户确认。

## 六、待补测接口清单

| 模块 | 待补测重点 | 建议执行方式 |
| --- | --- | --- |
| 登录认证 | 正确登录、错误登录、退出后 Token 失效、无 Token 访问 | curl 或 Postman |
| 权限控制 | 不同角色访问系统管理、考籍、审核、智能辅助接口 | 使用三个测试账号分别执行 |
| 考籍档案 | 创建、状态更新、归档、变更记录 | 使用临时考生和临时档案 |
| 材料管理 | 上传、预览、下载、删除、格式错误 | 使用临时图片和 PDF |
| 免考申请 | 提交、修改、撤回、通过、驳回、重复申请 | 使用临时档案和材料 |
| 课程顶替 | 规则有效期、专业层次匹配、申请审核 | 使用测试规则和临时申请 |
| 转入转出 | 转入必填来源省份、转出必填目标省份、转出审核联动档案状态 | 使用临时转考申请 |
| 毕业申请 | 资格校验、资格不通过阻断、审核通过联动毕业状态 | 使用满足和不满足资格的档案各一条 |
| 智能辅助 | 算法服务正常、算法服务不可用、异常输入、结果格式 | 后端和算法服务同时启动后执行 |

## 七、回归验证建议

1. 每次修复后先执行 `cd backend && mvn test`。
2. 启动 MySQL、后端和算法服务后执行登录与健康检查。
3. 使用 `admin` 执行系统管理和全量接口冒烟测试。
4. 使用 `record_manager` 验证考籍、材料和业务申请提交。
5. 使用 `auditor` 验证审核流程和无权限访问系统管理接口。
6. 对智能辅助接口同时验证算法服务可用和不可用两种状态。
7. 将所有失败项登记为明确的问题条目，包含复现步骤、实际结果、期望结果、影响范围和建议修复方向。
