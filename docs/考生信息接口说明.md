# 考生信息接口说明

## 一、说明

本文档对应第三阶段 3.2 任务，说明考生信息新增、修改、删除、分页查询、详情查询和导入预留接口。

所有接口统一返回格式如下：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

## 二、接口列表

| 功能 | 方法 | 地址 |
| --- | --- | --- |
| 分页查询考生 | GET | `/api/candidates/page` |
| 查询考生详情 | GET | `/api/candidates/{id}` |
| 新增考生 | POST | `/api/candidates` |
| 修改考生 | PUT | `/api/candidates/{id}` |
| 删除考生 | DELETE | `/api/candidates/{id}` |
| 导入预览预留 | POST | `/api/candidates/import/preview` |

## 三、分页查询考生

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageNo | number | 否 | 当前页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 关键字，可匹配姓名、身份证号、准考证号 |

## 四、新增和修改考生

请求体字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 考生姓名 |
| gender | string | 否 | 性别 |
| idCard | string | 是 | 身份证号，系统内唯一 |
| admissionNo | string | 否 | 准考证号，填写时系统内唯一 |
| birthDate | string | 否 | 出生日期，格式 `yyyy-MM-dd` |
| nation | string | 否 | 民族 |
| politicalStatus | string | 否 | 政治面貌 |
| educationLevel | string | 否 | 学历层次 |
| majorName | string | 否 | 报考专业 |
| phone | string | 否 | 联系电话 |
| email | string | 否 | 电子邮箱 |
| address | string | 否 | 联系地址 |
| status | string | 否 | 考生状态：`NORMAL` 正常，`DISABLED` 停用 |

## 五、导入预留接口

导入预留接口使用 `multipart/form-data` 上传文件，字段名为 `file`。

当前版本仅校验文件非空并返回导入模板字段，不解析文件内容，不写入考生数据。后续可在该接口基础上扩展 Excel 解析、数据校验和正式导入。
