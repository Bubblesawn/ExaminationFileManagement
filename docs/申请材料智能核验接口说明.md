# 申请材料智能核验接口说明

本文档对应第四阶段 4.11 任务，说明申请材料分类、缺失材料提示和异常材料提醒接口。

## 一、接口目标

- 对业务申请已上传材料进行分类，返回每份材料的类别、置信度和处理建议。
- 根据申请类型返回必交材料清单，并提示缺失材料。
- 对低质量、低置信度、登记类别不一致、重复类别等异常材料给出提醒。

## 二、后端封装接口

### 1. 手工传入材料明细核验

| 项目 | 内容 |
| --- | --- |
| 请求方式 | `POST` |
| 请求路径 | `/api/ai/application-material-audit` |
| 认证方式 | 用户登录 Token |
| Content-Type | `application/json` |

请求示例：

```json
{
  "businessId": 1001,
  "applicationType": "EXEMPTION",
  "applicantName": "张三",
  "materials": [
    {
      "materialId": 10,
      "fileUrl": "/api/materials/10/preview",
      "fileName": "身份证.jpg",
      "materialTypeHint": "ID_CARD",
      "uploadedCategoryCode": "ID_CARD"
    }
  ]
}
```

### 2. 按业务申请 ID 自动核验

| 项目 | 内容 |
| --- | --- |
| 请求方式 | `POST` |
| 请求路径 | `/api/ai/applications/{applicationId}/material-audit` |
| 认证方式 | 用户登录 Token |

后端会读取 `business_application.material_ids_json`，校验材料属于当前考籍档案，并自动组装材料文件地址、原始文件名和登记类别后调用算法服务。

## 三、响应字段

| 字段 | 说明 |
| --- | --- |
| `required_categories` | 当前申请类型必交材料类别。 |
| `classified_materials` | 已上传材料分类结果。 |
| `missing_materials` | 缺失材料提示。 |
| `abnormal_materials` | 异常材料提醒。 |
| `summary.material_count` | 已核验材料数量。 |
| `summary.missing_count` | 缺失材料数量。 |
| `summary.abnormal_count` | 异常材料数量。 |
| `suggested_action` | 整体建议动作：`ACCEPT`、`REVIEW`、`REJECT`。 |
| `need_manual_review` | 是否建议人工复核。 |

## 四、处理规则

- 免考申请要求身份证材料、成绩单材料、免考证明材料。
- 课程顶替申请要求身份证材料、成绩单材料、学历证书材料。
- 考籍转入转出申请要求身份证材料、准考证材料、成绩单材料。
- 毕业申请要求身份证材料、学历证书材料、成绩单材料、考生照片。
- 支持图片和 PDF 材料参与核验；PDF 跳过图片清晰度检测，只按文件名、登记类别和材料提示进行分类。
- 缺少必交材料或存在高风险异常时，整体建议为 `REJECT`；存在一般异常时建议为 `REVIEW`；材料齐全且无异常时建议为 `ACCEPT`。
