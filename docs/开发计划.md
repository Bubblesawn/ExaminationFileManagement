# 开发计划

## 一、人员分工

| 角色 | 主要负责人 | 职责范围 |
| --- | --- | --- |
| 后端负责人 | 成员 A | Spring Boot 后端工程、数据库设计、权限认证、业务接口、接口文档、后端测试。 |
| 前端负责人 | 成员 B | Vue3 前端工程、页面开发、组件封装、接口联调、交互体验、前端测试。 |
| 算法与集成负责人 | 成员 C | FastAPI 算法服务、智能辅助能力、文件识别处理、服务集成、部署联调。 |

> 注：成员 A、成员 B、成员 C 可在实际执行前替换为真实姓名。

## 二、阶段安排

## 第一阶段：基础工程

### 阶段目标

- 完成后端、前端、算法服务三端项目初始化。
- 建立统一的工程规范、接口规范和本地开发环境。
- 打通前后端和算法服务的基础调用链路。

### 任务分工

| 负责人 | 任务 |
| --- | --- |
| 成员 A | 完成 Spring Boot 后端项目初始化；配置统一响应、全局异常、跨域、分页、接口文档；设计基础数据库结构。 |
| 成员 B | 完成 Vue3 前端项目初始化；搭建路由、状态管理、请求封装、基础布局；准备登录页和主框架页面。 |
| 成员 C | 完成 FastAPI 算法服务初始化；设计算法服务接口规范；提供健康检查接口和示例识别接口。 |

### 交付物

- 后端基础工程可启动。
- 前端基础工程可启动。
- 算法服务基础工程可启动。
- 三端接口调用示例完成。

## 第二阶段：系统管理

### 阶段目标

- 完成系统登录认证和基础权限管理。
- 支持用户、角色、菜单和日志管理。
- 为后续业务模块提供权限控制基础。

### 任务分工

| 负责人 | 任务 |
| --- | --- |
| 成员 A | 实现登录认证、Token 校验、用户管理、角色管理、菜单管理、操作日志、登录日志接口。 |
| 成员 B | 开发登录页、首页布局、用户管理页、角色管理页、菜单管理页、日志查询页。 |
| 成员 C | 配合完成接口联调；补充系统运行监控接口；整理算法服务接入权限方案。 |

### 交付物

- 登录、退出、权限校验流程可用。
- 用户、角色、菜单、日志管理页面可用。
- 接口文档和联调记录完成。

## 第三阶段：考籍核心业务

### 阶段目标

- 完成考生基础信息和考籍档案管理。
- 支持材料上传、预览、状态维护和变更记录。
- 建立核心业务数据的增删改查闭环。

### 任务分工

| 负责人 | 任务 |
| --- | --- |
| 成员 A | 设计考生、档案、材料、状态、变更记录相关数据表；实现核心业务接口和文件存储接口。 |
| 成员 B | 开发考生信息管理、考籍档案管理、材料上传预览、状态维护、变更记录页面。 |
| 成员 C | 接入材料预处理能力；提供图片格式校验、清晰度检测、基础分类接口。 |

### 交付物

- 考生基础信息管理可用。
- 考籍档案管理可用。
- 材料上传、预览、状态维护和变更记录可用。
- 材料智能预处理接口完成初步联调。

## 第四阶段：业务流程

### 阶段目标

- 完成免考、课程顶替、考籍转入转出、毕业申请等业务流程。
- 支持申请提交、审核、驳回、通过和流程记录查询。
- 保证业务流转与档案状态联动。

### 任务分工

| 负责人 | 任务 |
| --- | --- |
| 成员 A | 实现免考申请与审核、课程顶替申请、考籍转入转出、毕业申请与审核接口；处理流程状态流转。 |
| 成员 B | 开发各类申请表单、审核列表、详情页、流程记录页；完善表单校验和提示。 |
| 成员 C | 为申请材料提供智能识别辅助；支持材料分类、缺失项提示和异常材料提醒。 |

### 交付物

- 免考申请与审核流程可用。
- 课程顶替申请流程可用。
- 考籍转入转出流程可用。
- 毕业申请与审核流程可用。
- 流程记录和状态联动可用。

## 第五阶段：智能辅助

### 阶段目标

- 完成图像分类、目标检测、图像分割、智能问答、语音识别和语音播报能力。
- 将智能辅助能力接入核心业务场景。
- 提升材料审核和业务办理效率。

### 任务分工

| 负责人 | 任务 |
| --- | --- |
| 成员 A | 提供智能辅助调用接口、结果存储接口和业务数据关联接口；完成后端权限与日志记录。 |
| 成员 B | 开发智能辅助结果展示、人工确认、问答入口、语音识别输入和语音播报控制页面组件。 |
| 成员 C | 实现图像分类、目标检测、图像分割、智能问答、ASR 语音识别、TTS 语音播报服务；输出调用说明。 |

### 交付物

- 图像分类、目标检测、图像分割服务可调用。
- 智能问答服务可调用。
- ASR 语音识别和 TTS 语音播报可用。
- 智能辅助结果能够在业务页面中展示和确认。

## 三、协作节奏

- 每日同步开发进度、阻塞问题和当日计划。
- 每个阶段结束前进行一次联调验收。
- 成员 A 负责维护后端接口文档。
- 成员 B 负责维护前端页面清单和联调问题记录。
- 成员 C 负责维护算法服务说明和模型接口说明。
- 重要接口、关键业务逻辑和算法服务入口需要补充严格的 Doxygen 注释。

## 四、阶段验收标准

- 代码能够正常启动并通过基础测试。
- 页面主流程可操作，关键提示清晰。
- 接口文档、数据结构和联调记录完整。
- 关键代码已经补充 Doxygen 注释。
- 阶段功能经过三人交叉验证后再进入下一阶段。
