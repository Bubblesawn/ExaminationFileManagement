# 开发计划

## 第一阶段：基础工程

- 完成 Spring Boot 后端项目初始化。
- 完成 Vue3 前端项目初始化。
- 完成 FastAPI 算法服务初始化。
- 建立统一响应、全局异常、接口文档、跨域、分页配置。

## 第二阶段：系统管理

- 登录认证。
- 用户管理。
- 角色管理。
- 菜单管理。
- 操作日志。
- 登录日志。

## 第三阶段：考籍核心业务

- 考生基础信息管理。
- 考籍档案管理。
- 材料上传与预览。
- 档案状态维护。
- 档案变更记录。

## 第四阶段：业务流程

- 免考申请与审核。
- 课程顶替规则和申请。
- 考籍转入转出。
- 毕业申请与审核。

## 第五阶段：智能辅助

- 图像分类。
- 目标检测。
- 图像分割。
- 智能问答。
- ASR 语音识别。
- TTS 语音播报。
