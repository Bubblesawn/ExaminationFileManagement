# 材料预处理接口说明

## 一、接口目标

第三阶段 3.10 实现材料上传后的基础预处理能力，包括：

- 材料格式校验：校验图片、PDF 等常见材料格式和文件大小。
- 图片清晰度检测：对图片材料给出清晰度评分、等级和处理建议。
- 基础材料分类：根据文件名、材料类型提示和业务场景返回材料类别候选结果。

## 二、算法服务接口

### 1. 请求信息

| 项目 | 内容 |
| --- | --- |
| 请求方式 | `POST` |
| 接口地址 | `/api/material-preprocess` |
| 认证方式 | 请求头 `X-Internal-Api-Key` |
| Content-Type | `application/json` |

### 2. 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file_url` | string | 是 | 材料文件地址 |
| `business_id` | number | 否 | 关联业务 ID |
| `scene` | string | 否 | 业务场景，例如 `MATERIAL_AUDIT`、`EXEMPTION` |
| `file_name` | string | 否 | 原始文件名 |
| `content_type` | string | 否 | 文件 MIME 类型 |
| `file_size_kb` | number | 否 | 文件大小，单位 KB |
| `material_type_hint` | string | 否 | 前端或业务系统提供的材料类型提示 |

### 3. 请求示例

```json
{
  "file_url": "/uploads/materials/idcard-clear.jpg",
  "business_id": 1001,
  "scene": "MATERIAL_AUDIT",
  "file_name": "身份证材料.jpg",
  "content_type": "image/jpeg",
  "file_size_kb": 512,
  "material_type_hint": "身份证"
}
```

### 4. 响应示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "business_id": 1001,
    "file_url": "/uploads/materials/idcard-clear.jpg",
    "file_name": "身份证材料.jpg",

      "valid": true,
      "file_suffix": ".jpg",

    "clarity": {
      "image": true,
      "score": 0.92,
      "level": "CLEAR",
      "readable": true,
      "issues": [],
      "suggestion": "图片清晰度满足自动预处理要求。"
    },
    "category_code": "ID_CARD",
    "category_name": "身份证材料",
    "confidence": 0.9,
    "candidates": [
      {
        "category_code": "ID_CARD",
```

## 三、后端封装接口

### 1. 请求信息

| 项目 | 内容 |
| --- | --- |
| 请求方式 | `POST` |
| 接口地址 | `/api/ai/material-preprocess` |
| 认证方式 | 用户登录 Token |
| Content-Type | `application/json` |

### 2. 前端请求字段

后端接口支持前端使用驼峰字段提交，并在调用算法服务时转换为下划线字段。

| 前端字段 | 算法服务字段 | 说明 |
| --- | --- | --- |
| `fileUrl` | `file_url` | 材料文件地址 |
| `businessId` | `business_id` | 关联业务 ID |
| `scene` | `scene` | 业务场景 |
| `fileName` | `file_name` | 原始文件名 |
| `contentType` | `content_type` | 文件 MIME 类型 |
| `fileSizeKb` | `file_size_kb` | 文件大小，单位 KB |
| `materialTypeHint` | `material_type_hint` | 材料类型提示 |

## 四、结果字段说明

| 字段 | 说明 |
| --- | --- |
| `format_validation.valid` | 材料格式是否可处理 |
| `format_validation.issues` | 格式问题列表，可能包含 `UNSUPPORTED_MATERIAL_FORMAT`、`FILE_SIZE_EXCEEDED`、`CONTENT_TYPE_MISMATCH` |
| `clarity.score` | 图片清晰度评分，范围 0 到 1 |
| `clarity.level` | 清晰度等级：`CLEAR`、`REVIEW`、`BLURRY`、`NOT_IMAGE` |
| `category_code` | 最可能的材料类别编码 |
| `candidates` | 材料类别候选项 |
| `suggested_action` | 建议动作：`ACCEPT`、`REVIEW`、`REJECT` |
| `need_manual_review` | 是否需要人工复核 |

## 五、处理规则

- 当前支持材料后缀：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.webp`、`.pdf`。
- 当前默认最大文件大小为 10240 KB。
- PDF 材料仅做格式校验和基础分类，图片清晰度检测结果为 `NOT_IMAGE`。
- 文件名或地址包含 `blur`、`low`、`unclear` 时模拟低清晰度风险。
- 文件名或地址包含 `blocked`、`cover`、`occlusion` 时模拟遮挡风险。
