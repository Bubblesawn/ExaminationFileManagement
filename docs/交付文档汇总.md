## 二、系统交付物

| 类别 | 路径 | 说明 |
| --- | --- | --- |
| 后端服务 | `backend` | Spring Boot 后端，提供认证、权限、考籍、材料、业务流程、日志和智能辅助封装接口 |
| 前端应用 | `frontend` | Vue3 前端，提供登录、工作台、系统管理、考籍业务、流程办理和智能辅助页面 |
| 算法服务 | `algorithm-service` | FastAPI 算法服务，提供图像分类、材料预处理、材料核验、目标检测、图像分割、智能问答、ASR 和 TTS |
| 数据库脚本 | `sql/init.sql` | 数据库和表结构初始化脚本 |
| 演示数据脚本 | `sql/test-data.sql` | 角色、菜单、账号、考生、档案、材料、流程和审核样例数据 |
| 项目说明 | `README.md` | 项目概览和快速启动说明 |
