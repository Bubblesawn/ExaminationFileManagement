# 演示数据与演示流程

## 一、说明

本文档对应《实施计划》第六阶段 6.8“准备系统演示数据和演示流程”，用于说明演示环境初始化数据、演示账号、主业务演示路线和智能辅助演示路线。

准备时间：2026 年 5 月 28 日  
数据来源：`sql/test-data.sql`  
适用环境：本地 MySQL、Spring Boot 后端、Vue3 前端、FastAPI 算法服务。

## 二、演示环境准备

1. 初始化数据库：

```bash
mysql -uroot -p < sql/init.sql
mysql -uroot -p exam_record < sql/test-data.sql
```

2. 启动算法服务：

```bash
cd algorithm-service
python -m uvicorn app.main:app --host 127.0.0.1 --port 9000 --reload
```

3. 启动后端服务：

```bash
cd backend
mvn spring-boot:run
```

4. 启动前端服务：

```bash
cd frontend
npm run dev
```

5. 打开前端地址：

```text
http://localhost:5173
```

## 五、推荐演示路线

### 1. 登录与权限菜单

1. 使用 `admin/admin123` 登录。
2. 展示工作台统计和侧栏完整菜单。
3. 进入系统管理，查看用户、角色、菜单和日志。
4. 退出后使用 `record_manager/record123` 登录，展示系统管理菜单不可见。
5. 退出后使用 `auditor/audit123` 登录，展示审核相关菜单。

验收点：

- 登录成功后进入工作台。
- 不同角色菜单不同。
- 无权限页面不会暴露给普通账号。

### 2. 考籍主流程

推荐账号：`record_manager`

1. 进入“考生管理”，按姓名或准考证号查询 `张明`。
2. 进入“考籍档案”，查询 `KJ20260001`。
3. 查看档案基础信息、材料状态和档案状态。
4. 进入“档案变更记录”，选择或输入档案，查看状态和材料变更记录。
5. 可新增一个临时考生和临时档案，用于展示新增、编辑和校验能力。

验收点：

- 考生查询和档案查询可用。
- 档案状态、材料状态和变更记录可追踪。
- 新增数据不影响基础演示数据。

### 3. 材料审核与智能辅助

推荐账号：`auditor`

1. 进入“材料审核”，查询待审核材料。
2. 选择 `李晓雨课程免考证明.pdf` 对应记录。
3. 发起材料预处理或材料智能核验。
4. 查看分类候选、清晰度、缺失材料、异常材料和建议动作。
5. 人工确认审核意见。

验收点：

- 前端通过后端调用算法服务，不直接暴露内部密钥。
- 智能辅助结果可读，可作为人工审核参考。
- 算法服务不可用时页面应给出明确错误提示。

### 4. 免考申请流程

推荐账号：`auditor`

1. 进入“免考管理”。
2. 查询申请号 `MK20260001` 或申请人 `李晓雨`。
3. 查看申请详情、扩展字段和材料。
4. 查看流程记录。
5. 根据演示需要执行审核通过或驳回。

验收点：

- 申请列表、详情、审核和流程记录完整。
- 审核操作会形成审核记录。

### 5. 课程顶替流程

推荐账号：`auditor`

1. 进入“课程顶替”。
2. 查看顶替规则：`03708` 顶替 `12656`。
3. 查询申请号 `DT20260001`。
4. 查看申请详情、规则匹配信息和材料。
5. 根据演示需要执行审核通过或驳回。

验收点：

- 规则维护和申请办理在同一业务模块中可演示。
- 申请详情能够展示原课程、目标课程和申请原因。

### 6. 转入转出与毕业申请

推荐账号：`auditor`

1. 进入“转入转出”，展示转考申请列表和驳回样例。
2. 查看 `王博` 相关转考材料和驳回意见。
3. 进入“毕业管理”，查询 `陈思琪` 或 `KJ20260004`。
4. 执行毕业资格校验。
5. 查看毕业申请结果和流程记录。

验收点：

- 转考流程可展示材料问题和审核意见。
- 毕业申请可展示资格校验、审核和结果查询。

### 7. 智能问答与语音能力

推荐账号：任意拥有 `ai:view` 权限的账号。

1. 进入“智能辅助”。
2. 提问：`免考申请需要哪些材料？`
3. 查看回答、参考依据和建议追问。
4. 提问：`毕业申请如何做资格校验？`
5. 演示 ASR 和 TTS 控件时，优先使用浏览器支持录音和播放的环境。

验收点：

- 智能问答能够返回可读答案。
- 参考依据和建议问题正常展示。
- 语音能力在浏览器权限允许时可交互；浏览器不支持时应提示明确。

## 七、演示注意事项

1. 删除类操作只使用临时新增的数据，禁止批量删除基础演示数据。
2. 审核通过或驳回会改变申请状态；如需重复演示同一流程，建议先新增临时申请。
3. 材料预览依赖真实文件存在，样例脚本仅提供业务记录。
4. 智能问答可在未配置 DeepSeek API Key 时使用本地规则兜底；配置 API Key 后会优先尝试模型问答。
5. 演示结束后如需恢复基础状态，可重新执行 `sql/test-data.sql`；脚本使用唯一键和 `WHERE NOT EXISTS` 保护，适合重复导入基础数据。
